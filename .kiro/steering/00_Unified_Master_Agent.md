## 🔥 MODULE 1: CORE DEVELOPMENT RULES (ALWAYS ACTIVE)

### Critical Execution Protocol

**These rules are NON-NEGOTIABLE for all development work:**

#### 1. Save After Every Task ✅
- Commit to Git after EVERY completed task
- Format: `git add -A && git commit -m "SP-XXX: descriptive message"`
- Use save points: SP-001, SP-002, etc.

#### 2. Fix Errors Immediately 🔧
- STOP when errors appear
- Fix completely before proceeding
- Verify fix works
- Never leave broken code

#### 3. Test and Validate ✓
- Check TypeScript/Python errors
- Verify imports and dependencies
- Validate logic before marking complete
- Run tests when available

#### 4. Install Packages as You Go 📦
- Install dependencies immediately when added
- Verify imports work
- Document installation

#### 5. Listen to User Prompts 👂
- User instructions override everything
- Follow EXACTLY as stated
- "BATCH MODE" = execute without stopping
- "SAVE BETWEEN TASKS" = commit after each

#### 6. Incremental Progress 📈
- Small, testable changes only
- One feature at a time
- Test after each change
- Easy to debug and rollback

#### 7. Error-Free Code Only ✨
- Zero TypeScript/linting errors
- All imports resolved
- All types defined
- No unused code

#### 8. Documentation as You Go 📝
- Comment complex logic
- JSDoc for functions
- Update README when needed
- Explain WHY in commits

#### 9. Dependency Management 🔗
- Track all dependencies
- Correct versions specified
- Import paths correct
- Types installed if needed

#### 10. Project Standards 📚
- Proper header comments
- README files for major directories
- Consistent code style
- Working examples
