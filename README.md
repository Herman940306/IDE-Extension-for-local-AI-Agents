# AuraIA: A Next-Generation Cognitive AI Partner for VS Code

![AuraIA Logo](assets/AuraIA_logo.jpg)

AuraIA is not just another AI assistant; it is a sophisticated, privacy-first cognitive architecture designed to serve as a true coding partner. Built with a clear vision and a defined personality, AuraIA aims to provide developers with a calm, insightful, and supportive assistant that deeply understands the context of their work.

At its core, AuraIA operates on a multi-layered model routing system inspired by dual-process cognitive theory ("System 1" and "System 2" thinking). This allows it to be both incredibly fast for simple tasks and deeply analytical for complex ones, ensuring a fluid and intuitive developer experience. All of this is achieved with a local-first approach that respects user privacy, keeping your code on your machine by default.

## The AuralA Persona: Your Calm Coding Partner

Unlike generic AI tools, AuraIA is engineered with a distinct personality. As defined in its core vision, the persona is:

* **Calm and Supportive:** Engages with a professional, warm, and human-centric tone.
* **Insightful and Factual:** Provides clear, empathetic, and jargon-free explanations.
* **A True Partner:** Helps developers reason, create, and refine with confidence, acting as a supportive peer rather than just a tool.

This persona is primarily brought to life by a dedicated `Conversational Agent` (powered by models like `gemma3:12b`), ensuring that all user-facing communication is polished, natural, and helpful.

## The AuralA Cognitive Architecture

AuraIA’s standout feature is its advanced, multi-layered cognitive architecture, which intelligently orchestrates a suite of specialized local LLMs to handle requests.

1. **System 1: Fast Reasoning & Triage**
    * **Model:** `qwen3:8b`
    * **Role:** Acts as the initial point of contact. It instantly interprets user intent, handles quick questions, and provides immediate suggestions. Its primary job is to classify the task and route it to the appropriate downstream system without delay.

2. **Task Router & Specialized Engines**
    * Based on the initial classification, the `Task Router` delegates the request to one of several specialized engines:
        * **Code Engine (`codellama:7b`):** Generates, refactors, and debugs code, producing rapid first-draft solutions.
        * **Conversational Agent (`gemma3:12b`):** Manages user-facing dialogue, crafts explanations, and generates documentation with the defined AuralA persona.
        * **Context Engine (`nomic-embed-text`):** A persistent engine that generates and queries vector embeddings, giving AuraIA a deep, semantic understanding of your project's codebase and history.

3. **System 2: Deep Reasoning & Verification**
    * **Model:** `deepseek-r1:8b`
    * **Role:** This is the analytical core. It validates the logic, correctness, and consistency of code generated by the `Code Engine`. It performs deeper reasoning to catch errors and ensure the final output is robust and reliable.

4. **Quality & Safety Pipeline**
    * **Safety Layer (`phi3:medium`):** Before any output is sent to the user, it is scanned for privacy violations, data leaks, and unsafe code patterns.
    * **Output Composer:** This final stage merges the rapid response from System 1 with the validated result from System 2, applies the `gemma3` persona for tone and clarity, and formats the final output for the IDE.

## Key Features

* **Advanced Cognitive Architecture:** A unique multi-layered system that mimics human thinking for both speed and accuracy.
* **Defined AI Persona:** A calm, supportive, and human-centric partner, not just a command-line tool.
* **Privacy-First Processing:** Leverages local LLMs via Ollama to ensure your code and data stay on your machine.
* **Sophisticated Model Routing:** Intelligently delegates tasks to the best model for the job, from quick intent classification to deep logical verification.
* **Deep Contextual Awareness:** Utilizes an embeddings-based `Context Engine` to maintain a rich understanding of your project.
* **End-to-End Quality Assurance:** A built-in verification and safety pipeline ensures all outputs are correct, safe, and polished.
* **Flexible and Extensible:** The modular architecture (FastAPI, `dependency-injector`) and optional dependencies (`crewai`) make it easy to extend and customize.

## Current Status & Getting Started

The project is stable and fully functional for end-to-end testing. The backend services, cognitive architecture, and frontend UI are all integrated and operational.

1. **Start the Backend**: Use the VS Code Task **`Tasks: Run Task > Python: Run API (Uvicorn)`**.
2. **Start the Frontend**: In a new terminal, navigate to `frontend` and run `npm run dev`.
3. **Interact**: Open the frontend URL (e.g., `http://127.0.0.1:5288`) and begin interacting with AuraIA.
