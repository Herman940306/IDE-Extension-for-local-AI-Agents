## 🆘 TROUBLESHOOTING

### Hook Not Showing Up

1. Restart Kiro IDE
2. Check file exists: `.kiro/hooks/aura-dev-master-godmode.kiro.hook`
3. Verify JSON syntax is valid
4. Check `"enabled": true` in hook file

### Hook Not Triggering

1. Ensure hook type is `"userTriggered"`
2. Check patterns include your file type
3. Try manual activation via Command Palette
4. Check Kiro output panel for errors

### MCP Not Connected

1. Check MCP server status in Kiro
2. Verify `ai-assistant-ml` server is running
3. Check `.kiro/settings/mcp.json` configuration
4. Restart MCP server from Kiro MCP view
